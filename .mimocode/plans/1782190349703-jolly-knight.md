## MERGING GUIDE (for user)

### Tools to merge:
- **CapCut** (free, mobile/desktop) — simplest
- **DaVinci Resolve** (free, professional)
- **Adobe Premiere Pro**

### Merge steps:
1. Import all 3 video parts
2. Place in order: Part 1 → Part 2 → Part 3
3. Add crossfade transitions (0.5s) between clips for seamless flow
4. The voiceover should flow naturally: "We are Weekend Movers. Your move… our weekend."
5. Add soft cinematic background music track (royalty-free)
6. Export as MP4, H.264, 1080p, 30fps
7. Keep file under 5MB for fast web loading
